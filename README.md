# Hotelparser

Apify actor that scrapes operator hotel pages and extracts services and hotel characteristics.

## Structure

The project follows the standard [Apify actor](https://docs.apify.com/actors/development) layout so it can be linked directly from a GitHub repository.
- entry point: `src/main.js`
- actor metadata: `.actor/actor.json`
- Dockerfile: `Dockerfile`

## Running

```bash
npm start
```
